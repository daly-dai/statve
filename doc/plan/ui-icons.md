## 一、需求（人话）

现在图标不齐，看起来像「缺」，其实一半是「每张图都长在它自己的坐标系里」。

实测（2026-11-18，`app/` 全扫）：

| 维度 | 现状 |
|---|---|
| 数量 | **13 个** 内联 `<svg>`，散在 **8 个文件** |
| viewBox（画布坐标系） | **6 种**：24×24（4 个）· 16×16（2）· 14×14（1）· 13×13（1）· 12×12（2）· 10×10（2） |
| 描边粗细（stroke-width） | **9 种**：1.2 / 1.3 / 1.4 / 1.5 / 1.6 / 1.7 / 1.8 / 2，外加一个纯填充矩形（无描边） |

⇒ 每个图标单独看都没错，并排放在同一条工具栏上就散了。**目标不是"加更多图标"，是"先让已有的看起来是同一套"**。

## 三、详细设计 · 规格（动工前要拍板的都标了 ⚠️）

```
24 × 24 网格
fill="none" · stroke="currentColor"
stroke-width: 1.75        ⚠️ 待拍板（lucide 是 2；我们现在多数 1.6–1.8）
stroke-linecap / linejoin: round
尺寸靠 width/height 覆盖（**不再用网格本身表达大小**）
```

**四条硬约束**：

1. **图标不进无障碍树**：每个图标组件默认 `aria-hidden="true"`，语义由按钮的 `aria-label` 承载。现在 13 个里只有 2 个带了 label，其余靠外层按钮 —— 收编时把这条变成默认，不再每个地方各写一次。
2. **大小与网格分离**：网格只有 24 一种，20px 的图标就是同一个组件加 `width={20}`。现在「10 网格的箭头」和「24 网格的箭头」是两份不同的东西，收编后只有一份。
3. **例外要列名，不许口头豁免**：见下面的例外清单。
4. **本次不新增功能图标**：只收编现有 11 个。想加新图标（附件、模型选择…）另开一行，避免"顺手扩范围"。

## 五、验收（都能一次跑出来）

1. **机器判据**：`grep -rn "<svg" app --include=*.tsx` 在 `app/components/ui/icons/` 与上面两处例外之外命中 = **0**。这是「不齐」永远不会再长回来的保证 —— 不靠记性。
2. **规格判据**：`ui/icons/index.tsx` 内每个图标 `viewBox="0 0 24 24"`、`strokeWidth={1.75}`（或统一在容器上给）、`stroke="currentColor"`、`linecap/linejoin=round`；一条正则能查。
3. **同族检查（人眼）**：1440 宽下四处截图并排看 —— 工具栏（发送/停止/圆环旁边）、会话行（⋯/＋）、审批弹窗（警告）、目录浏览（文件夹/箭头）：粗细与圆角看着是一家人。
4. **行为不变**：图标只换形状，**按钮尺寸、命中区、`aria-label` 一律不动**；改动前后 DOM 里按钮的 `getBoundingClientRect()` 一致。
5. 静态四件套：`tsc` 0 / `eslint` 0 / `prettier --check` 0 / 全量单测绿；`check-plan` 0。
6. **可访问性**：图标全部 `aria-hidden="true"`；有图标的按钮都有可读的 `aria-label`（用 `npx @axe-core/cli` 或手工 Tab 走一遍）。

## 六、⚠️ 缺什么才能定案（三个待拍板）

1. **线宽 1.75 还是 2**？lucide 原版是 2（更"重"、更像线性图标）；我们现有大概 1.6–1.8（更细）。建议 **1.75**：在 24 网格上比 2 略细、比 1.6 略实，且现有图标里最粗的那支（发送 1.8）几乎不用改观感。
2. **三处例外认不认**（`PenMark` logo、context-meter 圆环、停止按钮的填充方块）？建议认 —— 但它们必须在验收第 1 条的例外清单里**按名字列出**，否则那条判据会变成"看心情"。
3. **要不要加一条 ESLint 规则禁直接写 `<svg>`**（只允许 `ui/icons` 里写）？好处：把判据从"grep 一次"变成"提交就报"，与 C45 的路线一致；代价：多写一个自定义规则（项目里已有先例：`scripts/check-feedback-tokens.mjs` 那种「跑一下就报」的脚本，比 ESLint 自定义规则便宜）。建议：**先用脚本**（`scripts/check-icons.mjs`），等真的要拦提交再升级成钩子。
